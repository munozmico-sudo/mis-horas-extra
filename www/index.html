Precio y descanso

Lectura de fotos

Sin clave, la app usa reconocimiento de texto gratuito en el propio teléfono (bien para relojes digitales y máquinas de fichar). Con una clave de la API de Claude también lee relojes de agujas. La clave se guarda solo en este dispositivo.

Copia de seguridad

Los datos se guardan en este teléfono. Copia el texto y guárdalo (en Drive, en una nota o por correo). Para recuperarlo, pégalo aquí y pulsa Restaurar.
